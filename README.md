# Market Analysis and Stock Segmentation

## Project Overview

This project analyses S&P 500 companies using historical stock market data to identify patterns in stock performance, risk characteristics and trading activity.

The analysis applies weekly return calculations, beta estimation, an adapted RFM framework and unsupervised machine learning techniques.

## Objectives

* Collect and validate historical stock market data.
* Calculate weekly returns and beta.
* Develop adapted Recency, Frequency and Monetary (RFM) features.
* Apply Agglomerative Clustering and K-means.
* Compare clustering performance and sensitivity.
* Examine sector composition and potential business applications.

## Methodology

The project uses Python, Google Colab, Pandas, NumPy, Matplotlib and Scikit-learn.

The analysis covers data preparation, feature engineering, clustering, model comparison and business intelligence interpretation.
